올리기

1. 위에서 채널을 고르고 「로그인 창」으로 왼쪽 Studio 오른쪽 위 프로필이 그 채널인지 확인합니다. 다른 채널은 「+ 계정」으로 Chrome 프로필을 따로 만들어 한 번 로그인합니다.

2. 회차를 누르고 「▶ 올리기 → 이북 연동」. 예약 칸에 시각을 넣으면 그 시각에 공개되는 예약 공개로 올라갑니다(업로드는 지금, PC를 꺼도 됨).

3. 올린 뒤 로그에 올라간 채널 이름이 나옵니다. 잘못 올렸으면 「업로드 기록 지우기」 후 Studio 에서 영상을 지우세요.

예약

여러 회차를 골라 패턴(매일·간격·요일)과 시작일·시각을 정하면 빈 칸에 차례로 배치합니다. 「미리보기」로 시각을 확인한 뒤 「예약 걸기」를 누르면 한 편씩 Studio 「예약 공개」로 올리고 이북에 연동합니다. 이미 예약된 시각은 비켜 갑니다.

예약 공개 영상은 공개 시각 전까지 이북에서 재생되지 않습니다(비공개 상태).

멈췄을 때

영상 파일을 넣은 뒤 멈추면 같은 버튼을 다시 누르지 말고(초안이 하나 더 생김) 왼쪽 Studio 창에서 나머지를 직접 누르세요. 그다음 「직접 올렸으면 유튜브 주소」에 주소를 넣으면 이북에 연동됩니다.
