# 화이트보드형 강의 (파일럿)

이미 만든 강의를 **같은 원고, 같은 목소리, 같은 시간축** 그대로 두고 손글씨 화이트보드 화면으로 다시 굽는다.
화면 스타일은 lemo-opuscar의 Whiteboard Explainer를 따른다. 보드 한 장 위에서 카메라가 움직이고, 컷은 없다. 펜·손·커서는 그리지 않는다.

```
.venv\Scripts\python _new\whiteboard\wb_render.py --job adsp-26 --only L01
```

| 옵션 | 뜻 |
|---|---|
| `--only L01,L02` | 렌더할 강(비우면 전부) |
| `--sections s1-01` | 그 섹션만 렌더한다(결과 파일 이름에 `.preview`가 붙는다) |
| `--preview 40` | 강 앞부분 40초만 렌더한다(확인용) |
| `--stills` | 장마다 스틸 PNG를 `out_wb/L01/stills/`에 뽑는다 |
| `--burn` | 자막을 화면에 굽는다(손글씨 라벨). 기본은 굽지 않고, 화면 아래 14%를 비워 둔다 |
| `--foley-lu 18` | 마커 소리를 목소리보다 몇 LU 낮게 할지. 숫자가 클수록 작아진다 |
| `--workers 6` | 동시에 띄울 Chromium 수 |

## 결과
- 결과는 `jobs/<잡>/out_wb/<강>/`에 생긴다.
  - `<강>.mp4`: 최종 영상(−16 LUFS)
  - `<강>.srt`, `<강>.chapters.json`: 기존 `out/<강>/`에서 복사한 것이다. 길이가 초 단위까지 같아서 그대로 쓸 수 있다.
  - `parts/`, `scenes/`, `stills/`
- 속도: 이 PC에서 워커 6개로 9분짜리 섹션 하나에 약 7분, 강 하나(약 28분)에 약 20분 걸린다.

## 구성
| 파일 | 역할 |
|---|---|
| `wb_render.py` | 실행 파일. 장면 만들기 → 프레임 → 소리 → 잇기 순서로 돌린다 |
| `scene.py` | 언제 쓰는지를 정한다. 불릿은 그 말이 처음 나오는 자막 시각에 쓰고, 기출 카드는 질문 뒤 일정한 박자로 쓴다 |
| `page/main.js` | 어디에 쓰는지(배치), 카메라, 정답 장에서 문제로 되돌아가 주황 동그라미를 치는 장면 |
| `page/engine/hangul.js` | 한글 손글씨(글자마다 쓰는 방향으로 쓸어 가며 드러낸다) |
| `page/engine/svgwb.js` | 원고의 SVG 그림과 표를 마커 획으로 바꾼다 |
| `foley.py` | 획마다 마커 소리를 만든다(표준 라이브러리만 쓴다) |
| `page/engine/wb.js` | lemo-opuscar 엔진(MIT). 출처와 바꾼 곳은 `VENDORED.md`에 적어 두었다 |

음성은 다시 합성하지 않는다. 기존 `out/<강>/parts/<섹션>.mp4`의 오디오를 그대로 쓰므로, 그 파일이 먼저 있어야 한다(`run.bat render`).
