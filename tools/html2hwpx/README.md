# html2hwpx — HTML을 한글(HWPX)로

**파이썬 표준 라이브러리만 씁니다.** pip 설치도, 한컴오피스도 필요 없습니다. 파일 하나(`html2hwpx.py`)만 복사하면 어느 PC, 어느 프로젝트에서나 쓸 수 있습니다.

## 쓰는 법

```bat
:: 끌어다 놓기: .html 파일(여러 개 가능)을 html2hwpx.bat 위에 놓으면 각각 옆에 .hwpx 가 생깁니다
::   bat 옆에 form.hwpx 를 두면 그 양식으로 만듭니다
html2hwpx.bat 정답해설.html

:: 명령줄
python html2hwpx.py 입력.html -o 출력.hwpx                        :: 기본 46배판(188×257mm), 여백 15mm, 맑은 고딕
python html2hwpx.py 입력.html --page 210x297                     :: A4
python html2hwpx.py 입력.html --template 양식.hwpx --page keep    :: 회사 양식의 글꼴·스타일·바탕쪽·판형 그대로
```

## 회사 양식 쓰기

1. 한글에서 양식 문서를 **다른 이름으로 저장 → HWPX**로 저장합니다. `.hwp`는 바로 쓸 수 없습니다.
2. `--template`으로 그 파일을 줍니다.
   - 양식의 본문 내용은 버리고, 글꼴·문단 스타일·쪽 설정·바탕쪽(머리말·꼬리말)만 가져옵니다.
   - 바탕쪽의 글자는 `--head`로 바꿉니다. 기본값은 HTML의 `<title>`입니다. 이렇게 해야 다른 책 제목이 남지 않습니다.
3. 문단 스타일은 아래 이름으로 찾아 씁니다. 다른 이름이면 `--styles "body=*본문,h2=*1.제목"`처럼 짝을 바꿉니다. 양식에 없는 이름은 기본 모양으로 나갑니다.

| HTML | 양식 스타일 |
|---|---|
| 본문 `p` | `*본문` |
| `h1` | `*절제목` |
| `h2` | `*1.제목` |
| `h3` | `*(1)제목` |
| `h4` | `*1)제목` |
| 표 칸 | `*표내용` |

## 옮기는 것

| HTML | 한글 |
|---|---|
| `h1`~`h4`, `p`, `div`, `li`, `pre` | 문단. `li`와 `.ex`는 들여쓰기 |
| `b`·`strong`, `small`·`.m`·`.muted` | 굵게, 작은 회색 글씨 |
| `table`(`th`, `td`, `colspan`) | 진짜 한글 표. `th`는 굵게, 옅은 회색 바탕 |
| `img`(png·jpg·gif·bmp) | 그림. `style="width:22mm"`이면 그 폭, 아니면 원본 크기(본문 폭의 80% 이내) |
| `img`(svg) | 옆에 같은 이름의 `.png`가 있으면 그것을 씁니다. 없으면 윈도우 Edge(또는 Chrome)를 헤드리스로 띄워 PNG로 굽습니다 |
| 쪽 나눔 | `<style>`의 `break-before:page` 규칙(`.a+.a`, `.a.b`, `.a`)과 `style="break-before:page"` |
| 「1.」+발문처럼 짧은 머리 글자 뒤에 블록이 오는 구조 | 한 문단으로 잇습니다 |

줄 배치와 쪽 배치는 한글이 문서를 열 때 다시 계산합니다.
